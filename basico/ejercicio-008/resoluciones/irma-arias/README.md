# Ejercicio 008 - UPDATE para Fútbol Sala

## Descripción
Módulo de datos enfocado en la administración y actualización de estadísticas para equipos de fútbol sala, aplicando la sentencia `UPDATE` para modificar marcadores y estados.

## Orden de Ejecución
1. `ddl/schema.sql`
2. `dml/inserts.sql`
3. `dql/consultas.sql`

## Decisiones Técnicas
* Se incorporaron registros iniciales y sentencias `UPDATE` para reflejar actualizaciones de partidos recientes.
* Se estructuraron consultas analíticas con `ORDER BY` y cálculo de diferencia de goles.
