# Ejercicio-08

# Explicacion 
En este ejercicio practiqué el uso de la sentencia **UPDATE** en MySQL para modificar y actualizar datos existentes de forma controlada. Para mantener un enfoque profesional, implementé la solución desde cero utilizando la temática de una liga de **fútbol sala**, estructurando los scripts en DDL, DML y consultas de actualización acompañadas de su respectiva verificación (`SELECT`).

## Componentes Principales

* **`ddl/schema.sql`** → Creación de la base de datos y diseño relacional de las tablas `equipos_sala` y `jugadores` con restricciones de integridad.
* **`dml/inserts.sql`** → Carga de datos iniciales coherentes con la temática deportiva.
* **`dql/consultas.sql`** → Sentencias **UPDATE** aplicadas a escenarios reales (actualización individual de estadísticas de jugadores, aumentos masivos condicionales y actualización de puntajes de equipos) junto con consultas de verificación.
* **`README.md`** → Documentación general del ejercicio.
