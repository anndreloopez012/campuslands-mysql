# Módulo de Datos - Ejercicio 031

Solución desarrollada en **MySQL** aplicando criterios profesionales de diseño de bases de datos, validaciones y consultas de negocio.

## Estructura de la Solución
- **ddl/schema.sql**: Creación de la base de datos y tabla principal con restricciones `CHECK`.
- **dml/inserts.sql**: Inserción de 8 registros de prueba variados.
- **dql/consultas.sql**: 5 consultas analíticas con filtros, agregaciones (`AVG`, `SUM`, `COUNT`), ordenamientos y `LIMIT`.

## Instrucciones de Ejecución
Ejecuta los scripts en tu gestor MySQL en orden estricto:
1. Ejecutar `ddl/schema.sql`
2. Ejecutar `dml/inserts.sql`
3. Ejecutar `dql/consultas.sql`
