# Ejercicio 007 - ORDER BY para liga de fútbol

## Descripción
Módulo de datos enfocado en la clasificación de equipos de fútbol, aplicando ordenamientos avanzados con la cláusula `ORDER BY` y el uso de alias para reportes de rendimiento.

## Orden de Ejecución
Ejecuta los scripts en tu gestor MySQL en el siguiente orden:
1. `ddl/schema.sql`
2. `dml/inserts.sql`
3. `dql/consultas.sql`

## Decisiones Técnicas
* Se implementó un campo de puntos, goles a favor y goles en contra para permitir múltiples criterios de ordenamiento (tabla de posiciones).
* Se utilizaron alias claros en las consultas para presentar reportes profesionales de la liga.
