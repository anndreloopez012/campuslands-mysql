# Ejercicio-07

# Explicacion 
En este ejercicio practiqué el uso de la cláusula **ORDER BY** en MySQL para ordenar conjuntos de resultados de manera ascendente y descendente, así como ordenamientos múltiples por varias columnas y expresiones calculadas. Para mantener un enfoque profesional, implementé la solución desde cero utilizando la temática de una **liga de fútbol**, estructurando los scripts en DDL, DML y DQL de forma limpia y ordenada.

## Componentes Principales

* **`ddl/schema.sql`** → Creación de la base de datos y diseño de la tabla `equipos` con atributos estadísticos coherentes para la clasificación de fútbol.
* **`dml/inserts.sql`** → Carga de datos de prueba con registros reales y estructurados de equipos de la liga.
* **`dql/consultas.sql`** → Consultas de práctica utilizando **ORDER BY** con una o múltiples columnas, operadores de orden ascendente/descendente y columnas calculadas (diferencia de goles).
* **`README.md`** → Documentación general del ejercicio.
