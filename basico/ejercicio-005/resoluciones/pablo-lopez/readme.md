## Autor
Pablo López

## Descripción
Se creó una tabla llamada `reparaciones` para registrar los servicios realizados en un taller mecánico de motocicletas.

La solución incluye:

- Inserción de 8 registros.
- Cinco consultas utilizando SELECT para responder preguntas del negocio.
