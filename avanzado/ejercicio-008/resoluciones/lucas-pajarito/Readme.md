# ⚽ Ejercicio 008 - Roles y Permisos para Fútbol Sala

## 📌 Descripción general

Este proyecto implementa una base de datos relacional en **MySQL** para una academia técnica inspirada en **fútbol sala**. La solución fue desarrollada con enfoque profesional y tiene como objetivo practicar:

* Diseño de bases de datos.
* Integridad referencial.
* Organización de scripts SQL.
* Consultas de análisis.
* Creación de **roles y permisos** en MySQL.

El sistema permite registrar sedes, equipos, jugadores y estadísticas deportivas, además de definir distintos niveles de acceso para usuarios del sistema.
