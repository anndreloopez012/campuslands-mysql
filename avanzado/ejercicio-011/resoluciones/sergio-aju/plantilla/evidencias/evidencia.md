# Ejercicio 011 - CTE para pingpong

Solución basada en la plantilla oficial de Campuslands para el manejo de datos de ping pong utilizando MySQL y CTEs (Expresiones de Tabla Comunes).

## Estructura
- `ddl/schema.sql`: Creación de la base de datos y la tabla `avanzado_ejercicio_011`.
- `dml/inserts.sql`: Carga de registros simulados con categoría de ping pong.
- `dql/consultas.sql`: Consultas que incluyen la base sugerida y reportes avanzados utilizando CTEs.

## Ejecución
Ejecuta los scripts en el orden habitual:
1. `ddl/schema.sql`
2. `dml/inserts.sql`
3. `dql/consultas.sql`
